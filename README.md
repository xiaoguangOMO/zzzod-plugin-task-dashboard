# 任务完成看板（zzz_task_dashboard）

> **这是一个只读的查看工具，不是自动化脚本。** 它不改一条龙的任何流程，不启动游戏、不点击、不执行日常任务；只读取一条龙自己写的配置文件，把结果显示成一张表。

给「绝区零一条龙」用的插件：**一张表看完所有实例今天勾选了哪些任务、哪些已经做完了。**

## 它做了什么

| 行为 | 说明 |
| --- | --- |
| 往左侧导航加一页「任务看板」 | 插件加载后自动添加，点开才采集数据 |
| 读取每个实例勾选了哪些任务 | 读 `config/<实例号>/one_dragon/_group.yml` |
| 读取每项任务今天的运行结果 | 读 `config/<实例号>/app_run_record/<应用ID>.yml` |
| 显示汇总与表格 | 游戏日、完成数、每实例完成数、每项任务的状态与完成时刻 |

**它不会做的事**：不启动/操作游戏、不触发任何应用执行、不写入一条龙的配置、不联网、不收集任何信息。

数据只在内存里存在，关掉窗口就没了；插件没有自己的数据目录，卸载后不会留下任何文件。

## 安装

1. 把整个 `zzz_task_dashboard` 文件夹放进一条龙的 `plugins` 目录；
2. **完全退出**一条龙（不是最小化）再重新打开，插件在启动时加载；
3. 左侧导航会多出「任务看板」，位置在「画中画」下面、「点赞」上面。

日志里能看到：

```
任务完成看板：已添加到侧栏「任务看板」
```

## 三种打开方式

### 方式一：侧栏「任务看板」（推荐）

点左侧「任务看板」，切走再切回来会重新采集一次。

### 方式二：一条龙「应用运行」

左侧「应用运行」→ 找到「任务完成看板」→ 运行。窗口会以一条龙主窗口为父窗口弹出。

### 方式三：独立窗口（可选，不用打开一条龙主界面）

```
<一条龙目录>\.venv\Scripts\pythonw.exe <一条龙目录>\plugins\zzz_task_dashboard\standalone.py
```

会先出现「正在读取一条龙配置，请稍候…」，几秒后变成看板窗口。这条路只读取配置，同样不会启动游戏。

## 怎么看

- 每一行是一项任务（顺序就是你在一条龙里排的顺序）；
- 每一列是一个实例（`实例 01`、`实例 02`……）；
- 顶部汇总：`游戏日 20261112 · 共完成 17 / 18 项`，下面按实例列出 `8/9`、`9/9`；
- 默认只显示**至少有一个实例勾选**的任务；取消左下角「只看已勾选任务」可以看全部；
- 窗口开着时每 30 秒自动刷新，也可以点「刷新」。

### 单元格的含义

| 显示 | 含义 |
| --- | --- |
| `✓ 11-13 18:27` | 已完成，后面是完成的日期与时刻 |
| `✗ 11-13 18:27` | 运行过但失败了 |
| 未运行 | 勾选了，但今天还没跑 |
| 运行中 | 正在跑 |
| 未勾选 | 这个实例没勾这项任务 |
| 无记录 | 勾选了但读不到运行记录（极少见） |

鼠标悬停可以看更完整的运行信息。

### 展开详情

任务名前面带 `▸` 的可以点开——点一下任务名，下方会展开这个任务在各个实例上的配置细节，再点一下收起。

目前支持这类详情的任务：

| 任务 | 展开后能看到 |
| --- | --- |
| 体力刷取（`charge_plan`） | 每条计划：区域 · 任务名（难度）、已运行/计划次数；电量不足时的恢复方式；双倍活动、循环执行、跳过计划、每日重置等开关 |
| 迷失之地（`lost_void`） | 任务名、挑战配置、每天计划次数 |

详情同样只读，数据来自 `config/<实例号>/one_dragon/<应用ID>.yml`；没有配置时显示「还没有配置…计划」。

## 数据来源与「游戏日」

| 内容 | 文件 |
| --- | --- |
| 勾选了哪些任务 | `config/<实例号>/one_dragon/_group.yml` 的 `app_list` |
| 今天是否完成 | `config/<实例号>/app_run_record/<应用ID>.yml` |
| 任务详情（体力、迷失之地） | `config/<实例号>/one_dragon/<应用ID>.yml` |

完成状态用的是每项应用自己的「游戏日」判断（区服有凌晨刷新之类的偏移），所以和一条龙「今天会不会跳过这个应用」的判断基本一致，不会出现看板说做完了、一条龙又跑一遍的情况。

有一个例外：**体力刷取（`charge_plan`）**每次初始化都会把自己的运行记录重置成「未运行」，一条龙就是靠这一点让它每天反复执行。所以看板对这项不使用记录里的状态，而是看记录里的日期和运行时间——只要今天跑过就显示完成时刻，这样才不会把它一直显示成「未运行」。

## 权限说明

`plugin.json` 里声明的风险项是 `filesystem`：插件需要读取一条龙工作目录下 `config/<实例号>/` 里的上述配置与运行记录文件。除此之外不读写任何其他位置，也不写文件。

## 常见问题

**应用运行里没有「任务完成看板」**
说明插件没被加载。看 `.log/log.txt` 里有没有 `发现 x 个独立应用`，以及插件目录是不是少放了 `factory.py` / `const.py`（这两个文件名必须原样）。

**侧栏没有「任务看板」**
看日志有没有 `任务完成看板：已添加到侧栏`。如果没有，通常是插件加载时主窗口还没建好，重启一次一条龙即可。

**点运行后窗口没出现**
看日志里有没有 `任务完成看板：已请求打开窗口`。有的话按 Alt+Tab 找一下，窗口可能被主界面挡住或开到了副屏。

**数字和一条龙界面对不上**
看板读的是磁盘上的文件。刚在界面里改了勾选还没写回时，等一下再点「刷新」。

**想给别的账号加实例**
在一条龙「设置 → 实例」里加实例并勾上「加入一条龙」，看板会按实例自动多出一列。

## 卸载

直接删除 `plugins\zzz_task_dashboard` 目录并重启一条龙即可，不会残留配置或数据。
