# 任务完成看板 · 使用说明

**只读工具**：不启动游戏、不执行任务、不改一条龙的任何流程，只读取配置与运行记录。

## 安装

把 `zzz_task_dashboard` 放进一条龙的 `plugins` 目录，**完全退出**一条龙再重新打开。

## 打开

- **推荐**：左侧导航「任务看板」，点开即看；
- 或者：「应用运行」→「任务完成看板」→ 运行；
- 或者：用 `standalone.py` 单独开一个窗口（不需要打开一条龙主界面）。

## 表格怎么看

- 一行一个任务，一列一个实例；
- 顶部：`游戏日 20261112 · 共完成 17 / 18 项`，以及每个实例的完成数；
- 默认只列**至少有一个实例勾选**的任务，取消底部「只看已勾选任务」可看全部；
- 每 30 秒自动刷新，也能手动点「刷新」。

| 显示 | 含义 |
| --- | --- |
| `✓ 11-13 18:27` | 已完成（日期 + 时刻） |
| `✗ 11-13 18:27` | 跑过但失败 |
| 未运行 | 勾选了，今天还没跑 |
| 运行中 | 正在跑 |
| 未勾选 | 这个实例没勾这项任务 |
| 无记录 | 勾选了但读不到运行记录 |

## 展开详情

任务名前面带 `▸` 的可以点开：点一下任务名，下面会展开它在各实例上的配置细节，再点一下收起。

目前有详情的是「体力刷取」（每条计划的区域、任务、已运行/计划次数、电量恢复方式等）和「迷失之地」（任务、挑战配置、每天计划次数）。详情只读，没有配置时显示「还没有配置…计划」。

## 数据从哪来

- `config/<实例号>/one_dragon/_group.yml`：勾选了哪些任务；
- `config/<实例号>/app_run_record/<应用ID>.yml`：每项任务今天的运行结果。

「今天」按各应用自己的游戏日判断，和一条龙跳过的逻辑一致。例外是「体力刷取」：它每次初始化都会把记录重置成未运行（一条龙靠这个让它每天反复跑），所以看板对它改成看「今天有没有运行记录」，跑过就显示完成时刻。

## 常见问题

- **侧栏没有「任务看板」**：看日志有没有 `任务完成看板：已添加到侧栏`，没有就重启一次一条龙。
- **点运行后没看到窗口**：按 Alt+Tab，可能被主界面挡住或开在副屏。
- **数字对不上**：看板读磁盘文件，界面刚改的勾选还没写回时需要等一会儿再刷新。

## 隐私与权限

- 只读本地配置文件，不联网、不上传、不记录账号信息；
- 日志里只有应用 ID、实例序号这类技术信息，不含账号、密码或路径中的用户名；
- 没有自己的数据目录，卸载（删除插件目录）后不残留任何文件；
- `plugin.json` 声明的风险项为 `filesystem`，仅用于读取上述配置与运行记录。
